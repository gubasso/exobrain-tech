# Web servers

Notes on web servers and reverse proxies: Caddy, Nginx, and the tools around Nginx for certificates and proxy hosts.

- [Caddy](./caddy.md): Caddy as a loopback HTTP credential gateway, with the gh, glab, and git client settings that route through it, the probe results, and the checks still pending.
- [Nginx](./nginx.md): Nginx configuration, a generic configuration example, installation, running, and the follow-up work of certificates and HTTP/2.
- [Nginx and certbot](./nginx-certbot.md): certbot commands that issue a certificate for an Nginx site, with and without prompts.
- [Nginx installation from source](./nginx-installation-build-source.md): building Nginx from source with its build flags, adding a dynamic module, and fixing a fresh install.
- [Nginx Proxy Manager](./nginx-nginx-proxy-manager.md): the fields of a proxy host in Nginx Proxy Manager, and the SSL options to turn on.
